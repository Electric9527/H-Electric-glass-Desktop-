# H-Electric-glass Desktop

A liquid-glass desktop for Windows: taskbar, start menu, notification centre, quick settings, stage manager and desktop
widgets, with one glass material and spring motion throughout. See [README.md](README.md) (Chinese) for the feature list.

Built on every push to `main` by `.github/workflows/build.yml`; the package is published under Releases.

Based on [Atrium Desktop](https://github.com/wynter-yaxley/atrium-desktop) 2.6.0 (MIT); its copyright notice is kept in
[LICENSE](LICENSE), as the licence requires.
